ng-nudge - A Custom Linter to Nudge Your Angular App Toward Quality

USAGE
  npx ng-nudge [OPTIONS]

DESCRIPTION
  ng-nudge is a custom linter for Angular applications that enforces
  best practices and coding standards. It checks relationships between
  files that ESLint cannot verify.

CONFIGURATION
  Create .config/ng-nudge/rc.json to configure artifact types, rules,
  and policies. Custom extensions go in .config/ng-nudge/artifacts/,
  .config/ng-nudge/rules/, and .config/ng-nudge/policies/.

  In rc.json, you can set default options:
    "options": {
      "warnings": "all",      // all | none | error
      "verbosity": "normal"   // normal | quiet | silent
    }

OPTIONS
  --warnings=MODE   Set warning behavior:
                      all    - show all warnings (default)
                      none   - suppress warnings
                      error  - treat warnings as errors

  -q, --quiet       Only report failures (no passing artifacts, no summary)
  -s, --silent      No output, only exit code
  -d, --update-debt Run all checks, then update debt.tsv with current violations
  -h, --help        Show this help message

EXIT CODES
  0   All checks passed
  1   One or more violations detected
